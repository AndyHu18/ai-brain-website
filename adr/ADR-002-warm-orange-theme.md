# ADR-002: 暖橘 Hermès 風格配色決策

## Status
**Accepted** - 2026-01-05

## Context
AI 智能腦官方網站需要建立高端企業形象，以吸引 B2B 客戶與高淨值用戶。配色方案是品牌識別的核心元素，需要傳達專業、溫暖且值得信賴的形象。

### 考量因素
- 目標客群：企業決策者、高淨值個人用戶
- 品牌定位：高端 AI 智能解決方案提供者
- 視覺區隔：需與科技業常見的冷色調（藍、灰）做出差異化
- 無障礙標準：需符合 WCAG 對比度要求

## Decision
採用 **暖橘色 #E67E22** 作為品牌主色，搭配白色 #FFFFFF 與深灰 #2C3E50 建立完整配色系統。

### 配色靈感
- 參考 **Hermès 愛馬仕** 的經典橘色，傳達奢華與工藝精神
- 暖橘色在心理學上代表創意、熱情與親和力

### 完整色彩系統
```css
:root {
  --color-primary: #E67E22;        /* 主色：暖橘 */
  --color-primary-light: #F39C12;  /* 亮橘 */
  --color-primary-dark: #D35400;   /* 深橘 */
  --color-text: #2C3E50;           /* 主文字：深灰 */
  --color-background: #FFFFFF;     /* 背景：純白 */
  --color-accent: #FDF2E9;         /* 輔助背景：暖白 */
}
```

## Consequences

### 正面影響
- ✅ **傳達溫暖專業感**：橘色給人溫暖、有活力的感受
- ✅ **高端品牌聯想**：Hermès 風格的橘色自帶奢華感
- ✅ **視覺差異化**：在一片藍色科技網站中脫穎而出
- ✅ **良好可讀性**：深灰文字在白底上具備極佳對比度

### 潛在風險
- ⚠️ 橘色使用過度可能顯得過於活潑，需控制比例
- ⚠️ 需確保所有狀態（hover、active）都有對應的色彩變化
- ⚠️ 深色模式需要另行設計配色方案
